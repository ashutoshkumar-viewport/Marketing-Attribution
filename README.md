# Multi-Touch Marketing ROAS Attribution Matrix

An enterprise-grade business intelligence matrix that parses 50,000 multi-channel digital interaction log entries using **Python**, builds structural **First-Touch & Last-Touch Attribution** data pipelines, and deploys an error-proof **Blended ROAS Ledger** inside **Power BI** using conditional formatting automation.

---

## 🛠️ The Technical Stack
* **Data Cleansing & Transformation:** Python, Pandas
* **Model Aggregation Analytics:** NumPy
* **Business Intelligence Logic:** Power BI Desktop (Defensive DAX Architecture)
* **Data Visualization:** Seaborn, Power BI Canvas Grid

---

## 📊 Core Business Problems Solved

### 1. Funnel Position Discrepancy Auditing
* Built parallel Python data pipelines to aggregate and compare **First-Touch Revenue** (identifying top-of-funnel brand awareness drivers) against **Last-Touch Revenue** (identifying bottom-of-funnel customer conversion closers).
* Quantified structural data variances across platforms (Facebook Ads, Instagram Ads, Google Search, Email Marketing, Organic) to expose precisely where marketing budgets are generating pipeline value.

### 2. Zero-Spend Division Defended Ledger
* Solved a standard business intelligence data glitch: handled organic customer acquisition paths carrying zero ad spend. 
* Wrote an advanced, error-proof defensive DAX measure (`Adjusted Blended ROAS`) using `DIVIDE` and table filtering architectures to eliminate infinite ratio (`inf`) exceptions, cleanly locking the metric scorecard to a true blended performance ratio.

### 3. Conditional Capital Routing Panel
* Engineered a full-width **Operational Marketing Ledger Matrix** embedded with dynamic background color routing parameters. 
* Programmed automated conditional formatting triggers that flash soft pastel warning signals (Red) on ad platforms underperforming a 2.0x threshold, and growth signals (Green) on ultra-efficient conversion assets (like Email at 48.3x ROAS).
